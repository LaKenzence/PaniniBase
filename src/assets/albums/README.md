# Mascottes des albums

Dépose ici **une image par album**, nommée d'après l'année : `1970.webp`, `1974.png`, … `2026.webp`.
Elle remplace automatiquement le ballon dessiné sur la tuile de l'album. Inutile de toucher au code :
seuls les fichiers présents sont pris en compte.

- Format : carré, environ 1024×1024, personnage entier et centré
- **Fond transparent** (vraie transparence, pas un damier dessiné). Si l'outil n'y arrive pas,
  demande un **fond blanc uni** : le détourage se fait ensuite facilement.

## Pourquoi des mascottes originales

Les mascottes officielles (Juanito, Naranjito, Footix, Goleo, Zakumi, Fuleco…) appartiennent à la FIFA.
On utilise donc un **animal ou un symbole du pays hôte**, dessiné dans un style commun,
en évitant les animaux des mascottes officielles de la même édition.

## Style commun (à coller à la fin de chaque prompt)

> Original football mascot character, 3D cartoon style, glossy and friendly, full body, dynamic pose holding a football,
> centered, soft studio lighting, vibrant colors, plain pure white background, no text, no logo, no existing mascot.
